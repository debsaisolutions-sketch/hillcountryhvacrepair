# Hill Country HVAC Repair

Static lead-generation site for [hillcountryhvacrepair.com](https://hillcountryhvacrepair.com/). The homepage is plain HTML, CSS, and `js/leads.js` (no build step). Blog pages, `sitemap.xml`, and `robots.txt` are published as committed files.

## Deploys

Production deploys come from Git `main` only, through the Vercel Git integration. Do not run `vercel --prod` or any other CLI production deploy.
